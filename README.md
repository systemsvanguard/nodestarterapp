# nodestarterapp
Starter template for a Node.js Express framework with EJS templating and Bulma CSS framework.

## Node.js Starter App

Live **Site Demo** ~ [Node.js Starter App](https://hypervelocity.herokuapp.com/) 

![Node.js Starter App](http://ryanhunter.org/images/portfolio/highvelocitytuners.jpg)



## Steps to Install
- git clone https://github.com/systemsvanguard/nodestarterapp.git 
- cd nodestarterapp
- ensure your have Node & NPM pre-installed. Run commands 'node -v && npm -v'.
- npm install
- run 'node index.js', OR better yet, nodemon index.js  
- Runs on port 3000 --> http://localhost:3000/


## Features
- Node.js
- Bulma.io CSS framework 
- FontAwesome 5 icons
- Google Fonts
- Filler text from https://pirateipsum.me
